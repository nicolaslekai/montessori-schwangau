# Montessori Kinderhaus Schwangau

Neue Website für das Montessori Kinderhaus Schwangau (www.montessori-schwangau.de).

Statische Seite ohne Build-Schritt in `docs/` (GitHub Pages). Keine Cookies, kein Tracking, Schrift lokal eingebunden.

- `docs/index.html`: Startseite mit allen Bereichen
- `docs/impressum.html`, `docs/datenschutz.html`: Rechtstexte
- `docs/assets/`: Stylesheet, Schrift, Bilder, Kurzkonzeption (PDF)

Die Fotos sind KI-generierte Platzhalter (GPT Image 2.5) und werden durch echte Bilder aus dem Kinderhaus ersetzt.
